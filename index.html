03 / Projects

Selected work

MSc Dissertation · QUB

Snort Community Ruleset — ATT&CK Threat Coverage Analysis

A five-stage Python framework that parses all 4,017 Snort 3 Community rules across 27 classtype categories and measures how much of MITRE ATT&CK they actually cover, validated against ATT&CK STIX 2.1 (v19.1).

10.70%of rules map to ATT&CK
34rules cite revoked technique IDs
3,587unmapped rules classified by LLM
  • Direct and heuristic ATT&CK mapping from rule evidence — msg, content, PCRE, references, service and ports.
  • LLM classification with NVIDIA Nemotron 3 Ultra (550B) plus a manually adjudicated blind validation across Claude, ChatGPT and Gemini.
  • Coverage analysis of modern threats (ransomware, DNS abuse), detection-difficulty tiering and matplotlib visualisations.

CWE Vulnerability Analysis System

A Python/Flask threat-intelligence dashboard over the MITRE CWE dataset, with CIA-impact and CVE-ranked views — built secure by design.

  • XXE-safe XML parsing with defusedxml; 8 REST API endpoints and per-CWE detail pages.
  • Defence in depth: layered input validation and 7 security headers (CSP, HSTS, X-Frame-Options).
  • 5-stage GitLab DevSecOps pipeline — Flake8, Bandit SAST, pip-audit, pytest and a versioned build.

FaceGuard — AI Red Team / Blue Team Assessment

An attack chain against a CNN facial-recognition access-control system, from model theft to privilege escalation — then hardening it.

  • Black-box model stealing: a proxy CNN replicating the victim at ~98% accuracy.
  • FGSM and PGD attacks with ~99% transfer success, plus a targeted impersonation attack.
  • Madry et al. adversarial training to build Robust_FaceGuard and weigh the accuracy–robustness trade-off.
